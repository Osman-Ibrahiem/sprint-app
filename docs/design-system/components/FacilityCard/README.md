# FacilityCard

كارت المنشأة في الاكتشاف والبحث: صورة، ونوع الرياضة، والاسم، والجهة، والتوفر النهارده، والسعر حسب شريحة المستخدم.

## اللي بيتبعت للـ component

- `photo`: صورة المنشأة الحقيقية (16:9 تقريبًا). لحد ما الصور توصل: مساحة `surface-sunken` مكتوب فيها "صورة المنشأة"، مش صورة stock.
- `sport` و `requiresTrainer` و `isFree`: بيطلعوا tags فوق الصورة. "بمدرب" و"مجاني" بـ `primary-soft`.
- `name` (`headline`) و `owningUnit` وعدد الوحدات (`caption`، `ink-muted`).
- `availabilityToday`: عدد الأماكن أو المواعيد الفاضية. كتير = `success` مع ✓، قليل = `warning` مع ساعة، مفيش = `ink-muted` "مفيش مواعيد النهارده".
- `price`: السعر حسب شريحة المستخدم الحالي، ومعاه مين السعر ده ليه ("سعر الطلاب والعاملين" أو "السعر الكامل"). للضيف: السعرين.
- `onTap`: بيفتح المنشأة (compact) أو بيعرضها في ناحية التفاصيل (medium وأكبر).

## الشكل

- `surface` بزوايا `radius-lg`، و `shadow-card` في الـ light بس.
- padding `space-4`، وخط `line` فوق السعر.
- `layout`: `vertical` في الـ grid والاكتشاف، و `horizontal` (الصورة على الـ start بعرض 112) في قوايم البحث على compact.

## قواعد

- السعر اللي بيظهر هو اللي المستخدم هيدفعه فعلًا؛ مفيش "ابتداءً من" مضلل.
- العروض (لو اتفعّلت) بتظهر tag `volt` بنص `on-volt` ("خصم 30% مسائي") والسعر القديم مشطوب بـ `ink-muted`.
- لا تحط أكتر من 3 tags، ولا أزرار جوه الكارت؛ الكارت كله بيتضغط.
