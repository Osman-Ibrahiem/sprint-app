# QRCode

رمز الحضور جوه `BookingTicket`: المدرب بيمسحه عند الدخول (US-15). في الكود `SprintQrPainter` في `lib/core/widgets/booking_ticket/qr_painter.dart`.

## اللي بيتبعت للـ component

- `token`: الـ token الموقّع بتاع الحجز (`qrToken`)، مش رقم الحجز الخام.

## الشكل

- موديولات `qr-ink` على أرض `qr-ground` في الثيمين: غامق على فاتح دايمًا، لأن الماسحات محتاجة كده.
- مسافة هادية 12 حوالين الرمز، ومقاسه نص عرض التذكرة (340) زائد المسافة من الناحيتين.
- تصحيح أخطاء بمستوى M.

## قواعد

- لو الـ token فاضي أو أكبر من إنه يتحول QR، بيظهر مكانه "QR غير متاح" بدل رمز بايظ.
- بيختفي في الحجز اللي فات أو اتلغى، وتظهر الحالة مكانه.
- قارئ الشاشة بيقرا "رمز الحضور، بيتعرض للمدرب عند الدخول".
- ارفع سطوع الشاشة وهو ظاهر (README § اللون).
- لا تلوّنه بألوان الثيم، ولا تحط لوجو في نصه.
