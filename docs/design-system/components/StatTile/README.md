# StatTile

كارت مؤشر أداء في لوحة الإدارة: اسم المؤشر والفترة، والرقم، والتغيير عن الفترة اللي قبلها.

## اللي بيتبعت للـ component

- `label` والفترة ("نسبة الإشغال · الأسبوع ده") بخط `caption` ولون `ink-muted`.
- `value` بخط `number-lg` ولون `ink`، والوحدة ("ج.م") أصغر بلون `ink-muted`.
- `delta` و `period`: التغيير وبيتقارن بإيه.
- `higherIsBetter`: بيحدد لون التغيير. الإشغال والإيراد: الزيادة كويسة. الغياب والإلغاء: النقص كويس.
- `onTap` اختياري: بيفتح التقرير المفصل بنفس الفلاتر.

## الشكل

- `surface` بزوايا `radius-lg`، و `shadow-card` في الـ light، padding `space-4`.
- التغيير: سهم بيقول الاتجاه، واللون بيقول كويس (`success`) ولا وحش (`danger`)، والجملة بتقول الاتنين بالكلام.
- على compact كارتين جنب بعض أو تحت بعض، وعلى expanded وأكبر 3 أو 4 في الصف.

## قواعد

- الأرقام بحدود صحيحة ومقربة: نسب من غير كسور، وفلوس بفاصلة الآلاف.
- المؤشرات اللي بتظهر حسب نطاق المستخدم: العميد بيشوف كليته، والمشرف العام بيشوف الجامعة.
- لا تحط sparkline أو رسم جوه الكارت؛ الرسوم في صفحة التقرير.
