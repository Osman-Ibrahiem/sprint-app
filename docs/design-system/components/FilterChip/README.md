# FilterChip

chip فلتر بيتختار ويتشال (نوع الرياضة، الجهة المالكة، مجاني أو مدفوع) في فلاتر المنشآت والبحث والهوم. component واحد في Figma (`FilterChip`) وفي الكود (`SprintFilterChip` في `lib/core/widgets/`) بدل الـ chips الخاصة في كل شاشة (refactor 000، قرار 21، 2026-11-23).

## اللي بيتبعت للـ component

- `label`: اسم الفلتر بخط `label`.
- `selected`: مختار أو لأ.
- `trailing` اختياري: أيقونة في الآخر (مثلًا سهم "فلاتر أكتر" اللي بيفتح الشيت أو الـ popover).
- `onSelected`.

## الحالات

| الحالة | الشكل |
| --- | --- |
| غير مختار | `surface` وحد 1px `control-border`، نص `ink` |
| مختار | `primary-soft` وحد `primary`، نص `on-primary-soft`، ومعاه أيقونة صح `icon-sm` قبل الكلام، فالاختيار مش باللون لوحده |

## قواعد

- الحد `control-border` لأنه بيعرّف control (3:1 على كل أرض في الثيمين، قرار C1). مش `line` اللي للزينة بس وأضعف من كده، ومش لون خام.
- ارتفاع 48 على الأقل (`control-height`)، زوايا `radius-full`، والمسافة بين الـ chips `space-2`. الـ chips بتلف لسطر جديد مع النص الكبير.
- قارئ الشاشة بيقرا الـ chip كزرار اختيار بحالته: "سباحة، مختار".
- على الويب والديسكتوب: hover بـ `surface-sunken` للغير مختار، و `focus-ring` مع الكيبورد.
- لا تستخدم `volt` للمختار، ولا تشيل أيقونة الصح من المختار.
