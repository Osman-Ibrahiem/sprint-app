# AccountGatePrompt

نافذة "الخطوة دي محتاجة حساب" اللي بتظهر للضيف لما يحاول حاجة محتاجة حساب (الحجز، حجوزاتي، التوثيق، الحساب). في الكود `AccountGatePrompt` في `lib/features/auth/presentation/account_gate.dart`، و `requireAccount` هو اللي بيفتحها.

## اللي بيتبعت للـ component

- `reason`: ليه الحساب مطلوب، بيتحط في الجملة: "تسجيل الدخول أو إنشاء حساب {reason}" ("عشان تحجز"، "عشان تشوف حجوزاتك"…).
- `onChoose`: تسجيل الدخول أو إنشاء حساب.
- `onDismiss`: "مش دلوقتي".

## الشكل

- أيقونة قفل `icon-lg` بلون `ink`، وتحتها العنوان بخط `title` (header لقارئ الشاشة)، وبعده الجملة بخط `body` ولون `ink-muted`، في النص.
- 3 أزرار تحت بعض بعرض النافذة: "تسجيل الدخول" `primary`، و"إنشاء حساب" `secondary`، و"مش دلوقتي" `ghost`.
- بتظهر بشكل النظام (`showSprintSheet`): popup من تحت على iOS، و bottom sheet على Android، وحوار على الويب والديسكتوب (`adaptive.md`).

## قواعد

- بعد الدخول أو التسجيل المستخدم بيرجع لنفس الخطوة (`/sign-in?from=`)، والميعاد اللي كان اختاره فاضل مختار، والحجز نفسه محتاج ضغطة جديدة.
- القفل مش بيعمل حاجة لوحده: "مش دلوقتي" بيرجّع الضيف مكانه من غير ما يخسر اختياره.
- زرار `primary` واحد بس.
