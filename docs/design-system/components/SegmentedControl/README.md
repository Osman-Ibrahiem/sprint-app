# SegmentedControl

تبديل بين قايمتين («الجاية» و«اللي فاتت») في «حجوزاتي».

- مسار `surface-sunken` ارتفاعه 48 بزوايا `radius-md`، الشرايح متساوية، المختارة `surface` بنص `ink`، التانية `ink-muted`.
- الشريحة بترسم 40 لكن منطقة اللمس كلها 48.
- الأسهم بتحرّك الاختيار، والـ focus ring ظاهر. العدّاد جزء من النص («الجاية (3)») وبيتشال لما القايمة فاضية.
