# DemoCodeNotice

ملاحظة صغيرة "للعرض بس" في شاشة الكود، بتعرض آخر كود اتبعت للإيميل ده من صندوق البريد المحاكى (FR-023)، عشان العرض يكمّل من غير إيميل حقيقي. في الكود `DemoCodeNotice` في `lib/features/auth/presentation/widgets/`.

## اللي بيتبعت للـ component

- `email` و `purpose`: الإيميل ونوع الكود (تأكيد الحساب أو استرجاع الباسورد).

## الشكل

- `warning-soft` بزوايا `radius-md`، وأيقونة تجربة بلون `ink`.
- "للعرض بس" بخط `caption` ولون `ink-muted`، وتحتها "كود التجربة: {code}" بخط `label` والكود جوه LTR isolate.
- زرار "إخفاء" بيقفلها.

## قواعد

- مش بتظهر خالص لو أدوات العرض مقفولة (مفيش صندوق بريد محاكى) أو لسه مفيش كود، فالنسخة الحقيقية عمرها ما تكشف كود.
- لما الكود يتبعت تاني، الملاحظة بتتحدث لوحدها بالكود الجديد.
- بتتحط جوه `CodeEntry` في المكان المخصص ليها، مش في أي مكان تاني.
