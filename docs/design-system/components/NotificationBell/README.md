# NotificationBell

جرس الإشعارات في هيدر الشاشات الأربع الرئيسية على compact للحاجز المسجّل (FR-NTF-02). على medium وأكبر الإشعارات وجهة في الشريط الجانبي بالعدّاد، مفيش جرس. الزائر مبيشوفوش.

## اللي بيتبعت

- `unread`: عدد الإشعارات اللي لسه ما اتقرتش. `null` وقت التحميل (من غير بادج).
- `onTap`: بيفتح مركز الإشعارات.

## الشكل

- دايرة 48 بلون `surface` وأيقونة جرس 24 (مش بتتعكس في RTL).
- بادج `danger` بنص `on-danger` وخط `micro`، أقل عرض 18، بيختفي عند صفر وبيبقى «99+» بعد 99.
- قارئ الشاشة بيقول «الإشعارات، N إشعار جديد».
